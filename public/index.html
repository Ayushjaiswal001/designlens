How It Works

1

Enter URL

Paste any public website URL into the scanner.

2

Fetch & Parse

DesignLens safely loads the page and builds the DOM.

3

Run axe-core

WCAG 2.0, 2.1, and 2.2 A/AA rules are tested on the fetched HTML.

4

Review & Fix

Read suggestions, check history, and download a report.

Limitation: Automated testing identifies common accessibility issues but cannot guarantee full WCAG compliance or certify a website as accessible. Manual testing by people with disabilities is also essential. Results are a project-specific indicator, not an official WCAG certification.

More Accessibility Checks

Focused reviews for links, tables, page structure, media, controls, and documents

Scan a page to use these checks

Page-based checks use the latest scan. Keyboard, zoom, and PDF reviews are completed by you.

Automated results are review signals. Page HTML cannot prove that content works in every browser or for every person.

1. Link Checker

Find links with missing or vague names and broken links to sections on this page.

2. Table Checker

Review table captions and header cells. Some tables are for layout, so check the context.

3. Page Setup Checker

Review the page title, language, main region, landmarks, skip link, and zoom settings.

4. Alt Text Quality Review

Heuristics flag text for human review; they cannot decide whether a description is meaningful.

5. Audio and Video Checker

Find media players and check whether caption tracks are present. Transcripts and caption accuracy need review.

6. Form Error Review

Automated form findings plus a saved manual check of what happens when a form has errors.

7. Control Name Checker

Lists controls without a name in the fetched HTML. Review custom widgets in a browser too.

8. Focus and Skip Link Review

Use the live site with a keyboard, then save your review here.

9. Zoom and Reflow Review

HTML inspection can spot zoom-blocking settings. Check actual layout at larger zoom in a browser.

10. PDF Accessibility Review

Choose a PDF to open it locally and record a guided review. The file is not uploaded or automatically certified.
